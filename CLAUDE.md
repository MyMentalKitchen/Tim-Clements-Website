# Tim Clements Portfolio Website

## Project Overview
Personal portfolio website for Tim Clements — hospitality leadership coach, founder of My Mental Kitchen, and owner of The Gipsy Hill Smokehouse.

## Tech Stack
- Static HTML/CSS/JS (no framework)
- Google Fonts: DM Serif Display (headings), Libre Franklin (body)
- No build tools required — open `index.html` in a browser

## Site Structure
- `index.html` — Main single-page portfolio (hero, about, services, MMK programme, ventures, philosophy, testimonials, contact)
- `blog.html` — Blog listing page
- `blog-mental-health-in-hospitality.html` — Article: Mental Health in Hospitality
- `blog-top-6-tools-of-resilience-coaching.html` — Article: Top 6 Tools of Resilience Coaching
- `styles.css` — Global styles
- `blog.css` — Blog-specific styles
- `script.js` — Navigation, smooth scroll, scroll animations

## Brand
- Primary color: `#3B5240` (dark green)
- Background: `#F2F3EF` (warm off-white)
- Text: `#2A2D2A`
- Accent: `#C8956C`
